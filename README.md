# Zenmart — ishga tushirish

Bu loyiha HTML, CSS va JavaScript asosidagi front-end demo internet-do‘konidir.

## Ishga tushirish

1. `Zenmart` papkasini VS Code’da oching.
2. `index.html` faylini oching.
3. VS Code’da Live Server o‘rnatilgan bo‘lsa, `index.html` ustida o‘ng tugma bosing va **Open with Live Server** ni tanlang. Live Server bo‘lmasa, `index.html` faylini brauzerda ham ochishingiz mumkin.

## Asosiy sahifalar

- `index.html` — bosh sahifa
- `product/allpr.html` — mahsulotlar katalogi, qidiruv, kategoriya/brend filtri va saralash
- `product/chosenproduct.html` — mahsulot tafsilotlari
- `order/cart.html` — savatcha
- `order/checkout.html` — buyurtmani rasmiylashtirish
- `order/resived.html` — buyurtma tasdiqlash
- `mypage/mypagee.html` — shaxsiy kabinet
- `other/login.html` va `other/singuo.html` — demo kirish va ro‘yxatdan o‘tish
- `other/about.html` va `other/contact.html` — ma’lumot va aloqa sahifalari

## Eslatma

Savatcha, demo hisob va buyurtma ma’lumotlari brauzerning `localStorage` xotirasida saqlanadi. Bu loyiha hozircha front-end demo: server, haqiqiy foydalanuvchi autentifikatsiyasi, buyurtma bazasi yoki onlayn to‘lov tizimi ulanmagan.
